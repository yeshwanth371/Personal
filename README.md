# Personal Notes

This repository contains personal study notes organized by subject. The notes are stored as static HTML files for easy viewing in a browser and quick access during revision.

## Contents

The notes are grouped under the following topics:

- Indian Economy
- Indian Geography
- Internal Security
- Modern History
- Polity
- Science and Technology
- World Geography

## Structure

```text
Personal/
├── README.md
└── Notes/
    ├── Indian Economy/
    ├── Indian Geography/
    ├── Internal Security/
    ├── Modern History/
    ├── Polity/
    ├── Science and Technology/
    └── World Geography/
```

## How to use

1. Open the `Notes` folder.
2. Choose the subject you want to study.
3. Open any `.html` file in a browser to read the class notes or consolidated revision material.
4. Use the date in each filename to trace the lesson chronology.

## Notes

- Files are kept as standalone HTML pages for easy portability.
- Many folders contain both individual class notes and consolidated summaries.
- This repository is intended as a personal learning archive and can be expanded with more subjects or notes over time.
